Política de Privacidad

Saldo App

Última actualización: 6 de octubre de 2026

1. Introducción

Saldo App es una aplicación que permite a los usuarios consultar información relacionada con su cuenta y saldo mediante un proceso de autenticación.

La privacidad de los usuarios es importante para nosotros. Esta Política de Privacidad explica qué información puede utilizar Saldo App y con qué finalidad.

2. Información de inicio de sesión

Para utilizar determinadas funciones de Saldo App, el usuario puede proporcionar información necesaria para iniciar sesión en el servicio correspondiente, como entidad, código de usuario y contraseña.

Las credenciales necesarias para el inicio de sesión pueden almacenarse de forma segura en el dispositivo del usuario con el objetivo de permitir futuros accesos sin tener que introducir nuevamente los datos.

3. Uso de Google y Gmail

Saldo App utiliza los servicios de Google para permitir que el usuario seleccione una cuenta de Google durante determinados procesos de autenticación.

Cuando el usuario autoriza el acceso correspondiente, Saldo App puede utilizar el permiso de solo lectura de Gmail (gmail.readonly) para localizar el mensaje de seguridad enviado al usuario durante el proceso de inicio de sesión.

El acceso a Gmail tiene como finalidad exclusiva localizar el código temporal de seguridad necesario para completar la autenticación.

4. Datos de Gmail

Saldo App no utiliza el contenido de Gmail para publicidad, análisis de comportamiento, venta de información ni elaboración de perfiles.

La aplicación busca únicamente los mensajes necesarios para localizar el código temporal de seguridad.

El contenido de los mensajes de correo no se almacena permanentemente como parte de una base de datos de Saldo App.

El código temporal obtenido se utiliza únicamente para completar el proceso de autenticación correspondiente.

5. Cuenta de Google seleccionada

La cuenta de Google utilizada para un proceso de autenticación puede ser seleccionada por el propio usuario.

La elección de una cuenta de Google no se utiliza como identificador permanente de la cuenta del servicio al que el usuario inicia sesión.

6. Seguridad

Saldo App utiliza mecanismos de almacenamiento seguro disponibles en el dispositivo para proteger las credenciales que el usuario decide guardar.

Ningún método de almacenamiento o transmisión de información puede garantizar una seguridad absoluta. Sin embargo, se aplican medidas razonables para reducir los riesgos de acceso no autorizado.

7. Compartición de información

Saldo App no vende, alquila ni comercializa la información personal de sus usuarios.

La información no se comparte con terceros para fines publicitarios.

8. Servicios de terceros

Saldo App puede utilizar servicios proporcionados por terceros, incluyendo servicios de Google, para determinadas funciones de autenticación.

El uso de dichos servicios también está sujeto a las políticas y condiciones de los respectivos proveedores.

9. Eliminación de datos

El usuario puede solicitar la eliminación de los datos almacenados localmente por Saldo App mediante las funciones disponibles en la aplicación o desinstalando la aplicación del dispositivo.

10. Cambios en esta política

Esta Política de Privacidad puede actualizarse cuando sea necesario para reflejar cambios en la aplicación, sus funciones o requisitos legales.

La fecha de última actualización se mostrará al comienzo de esta página.
