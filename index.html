Sobre Saldo App

Saldo App es una aplicación diseñada para facilitar el acceso y consulta de información relacionada con la cuenta del usuario.

Durante el proceso de inicio de sesión, la aplicación puede solicitar autorización para consultar un mensaje específico de Gmail que contiene un código temporal de seguridad enviado al usuario.

El acceso a Gmail se utiliza únicamente para completar el proceso de autenticación solicitado por el servicio.
